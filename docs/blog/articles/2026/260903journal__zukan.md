# 「圖鑑」的英文？

「圖鑑」 這個詞很微妙，英文想不到可以直接翻譯的，因為不同領域會用不同的詞: Field guide、Illustrated guide、Illustrated handbook、Gallery、Picture Book, Collection, Compendium...等。英文反應出來的是使用情境，「圖鑑」 反應的是呈現的樣式 （有圖片+簡單說明文字，會稍微分類整理，有方便查詢的索引）。

<!-- more -->

我猜這應該是從日文的「図鑑 (ずかん)」 挪用來的，wikepedia上（寫"據說"）第一個用這個詞的是牧野富太郎的『[日本植物図鑑](http://www.hokuryukan-ns.co.jp/makino/index.php)』，取的真是好。

不知道用台語的話要怎麼講。

會想到這個問題就是我常常用zotero軟體整裡資料，tag都是用英文（只是為了排序跟懶的切換輸入法），對於圖鑑類的我一直不知道要怎麼下tag，很困擾 => 現在決定一律用 "zukan"。
